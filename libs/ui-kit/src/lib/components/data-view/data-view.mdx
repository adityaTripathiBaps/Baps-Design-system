# DataView

DataView lays out a collection with your own template per item, as a list or a grid. `baps-dataview` (also `baps-data-view`) wraps PrimeNG's `p-dataview` ([primeng.dev/dataview](https://primeng.dev/dataview)). Write its `#list`, `#grid`, `#header`, `#footer` and `#emptymessage` templates (or the same names as `pTemplate`) inside the tag, as PrimeNG documents them; the wrapper hands each to DataView under its name.

For rows of fields with sorting, selection and column control, use `baps-table` instead.

## Usage

```html
<baps-dataview [value]="centers" [layout]="layout">
  <ng-template #list let-items> … one row per item … </ng-template>
  <ng-template #grid let-items> … one card per item … </ng-template>
</baps-dataview>
```

## Events

`lazyLoad`, `page`, `sort`, `changeLayout`.

## Accessibility

DataView adds no roles of its own; the templates are the content. Use a list (`ul` / `li`) or headings in them where the items are a list, and keep the sort and layout controls labelled.
