# Password

`baps-password` is a password field with an optional strength meter and a show/hide toggle. It wraps PrimeNG's `p-password` ([primeng.dev/password](https://primeng.dev/password)), which PrimeNG v21 lists as InputPassword. The inner field is a `pInputText`, so it is the kit input in both brands (MyBKY 36px pill, Sampark 32px with a 4px radius), sizes included. It takes the full width of its container.

## Usage

```html
<label for="password">Password</label>
<baps-password inputId="password" [toggleMask]="true" formControlName="password" />
```

## Events

`focused`, `blurred`, `cleared`. The form gets the value itself.

## Accessibility

Name the field with a `<label for>` and `inputId`, or `ariaLabel`. Set `autocomplete` to `current-password` on a sign-in form and `new-password` where the user picks one, so password managers fill or suggest correctly.
