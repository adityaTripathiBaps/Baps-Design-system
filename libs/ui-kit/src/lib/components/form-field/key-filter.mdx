# KeyFilter

`bapsKeyFilter` blocks keystrokes and pastes that do not fit a pattern, on any text field. It is PrimeNG's `pKeyFilter` ([primeng.dev/keyfilter](https://primeng.dev/keyfilter)) as a host directive: no wrapper, the field keeps its own skin.

## Usage

```html
<input bapsInputText bapsKeyFilter="int" formControlName="age" />
<input bapsInputText [bapsKeyFilter]="noSpecial" />  <!-- noSpecial = /^[^<>*!]+$/ -->
```

Presets: `pint` (positive integer), `int`, `pnum` (positive number), `num`, `money`, `hex`, `email`, `alpha`, `alphanum`.

## Accessibility

A blocked key does nothing and says nothing. Say what the field accepts in its label or hint, so a screen-reader user knows why a character did not appear.
