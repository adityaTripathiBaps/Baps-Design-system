# PickList

PickList moves items between two lists (available and chosen) and lets the user order either. Use PrimeNG's `p-picklist` ([primeng.dev/picklist](https://primeng.dev/picklist)) with the `bapsPickList` directive. Both lists are the kit Listbox (MyBKY 16px radius, Sampark 4px; 14px rows; the header text inset like a row) and every control is a kit button.

For choosing a few items from a long list, `baps-multi-select` takes less room; reach for PickList when the chosen set is worked on as a list of its own.

## Usage

```html
<p-picklist bapsPickList [(source)]="available" [(target)]="assigned" dataKey="id"
            sourceHeader="Available" targetHeader="Assigned" [dragdrop]="true">
  <ng-template #item let-k>{{ k.name }}</ng-template>
</p-picklist>
```

## Events

`sourceChange` / `targetChange` (two-way), `onMoveToTarget`, `onMoveAllToTarget`, `onMoveToSource`, `onMoveAllToSource`, `onSourceReorder`, `onTargetReorder`, `onSourceSelect`, `onTargetSelect`, `onSourceFilter`, `onTargetFilter`.

## Accessibility

Each list has listbox semantics and the buttons carry labels from the locale. Give each list a header; `responsive` with a `breakpoint` stacks the lists on narrow screens.
