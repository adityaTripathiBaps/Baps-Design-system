# Tree

Tree shows a nested list that opens branch by branch: regions, zones and centres. `baps-tree` wraps PrimeNG's `p-tree` ([primeng.dev/tree](https://primeng.dev/tree)). Node text takes the brand text colour (MyBKY `#181b1d`, Sampark `#151414`), toggles and icons the secondary text colour, hover the brand's light grey, and a selected node the brand primary tint.

To pick one or more nodes in a form field, use `baps-tree-select`; for a tree with columns, `baps-tree-table`.

## Usage

```html
<baps-tree [value]="nodes" selectionMode="checkbox" [(selection)]="picked"></baps-tree>
```

`value` is a `TreeNode[]` (`key`, `label`, `icon`, `children`, `expanded`, `type`, `data`). Node templates are `pTemplate` types (a node's `type`, plus `default`), and so are `header`, `footer`, `empty` and the icons.

## Events

`selectionChange` (two-way with `[(selection)]`), `nodeSelect`, `nodeUnselect`, `nodeExpand`, `nodeCollapse`, `nodeDoubleClick`, `nodeDrop`, `lazyLoad`, `filtered`.

## Accessibility

PrimeNG renders a `tree` with `treeitem` rows and `aria-expanded` / `aria-selected`; the arrow keys move and open branches and Space selects. Give the tree an `ariaLabel` or label it with `ariaLabelledBy`.
