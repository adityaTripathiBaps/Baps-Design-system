# OrderList

OrderList lets the user put a list in order, with the side buttons or by dragging. `baps-orderlist` (also `baps-order-list`) wraps PrimeNG's `p-orderlist` ([primeng.dev/orderlist](https://primeng.dev/orderlist)). Its list is the kit Listbox in both brands (MyBKY 16px radius, Sampark 4px; 14px rows with the brand's selected bar), and the move buttons are kit buttons.

## Usage

```html
<baps-orderlist [value]="steps" dataKey="id" [dragdrop]="true" ariaLabel="Visit steps">
  <ng-template pTemplate="header">Visit steps</ng-template>
  <ng-template pTemplate="item" let-step>{{ step.name }}</ng-template>
</baps-orderlist>
```

OrderList reorders `value` in place and emits `reorder`. Use a `pTemplate="header"` template for a title: PrimeNG v21 accepts a `header` input but does not render it. Other templates: `empty`, `emptyfilter`, the move icons.

## Accessibility

Name the list with `ariaLabel` or `ariaLabelledBy`. PrimeNG gives it listbox semantics: the arrow keys move the focus, Space or Enter selects, and the move buttons carry labels from the locale (`moveUp`, `moveTop`, …).
