# OrgChart

OrgChart draws a tree top-down with connector lines: regions and centres, or people and who they lead. `baps-organizationchart` (also `baps-organization-chart`) wraps PrimeNG's `p-organizationchart` ([primeng.dev/organizationchart](https://primeng.dev/organizationchart)). Nodes, connectors and toggles take the brand's border and text colours (MyBKY `#e4ecf1` / `#181b1d`, Sampark `#e1e0e0` / `#151414`); a selected node takes the brand primary tint.

## Usage

```html
<baps-organizationchart [value]="tree" [collapsible]="true">
  <ng-template let-node pTemplate="person"> … </ng-template>
  <ng-template let-node pTemplate="default">{{ node.label }}</ng-template>
</baps-organizationchart>
```

`value` is a `TreeNode[]` with one root. A node's `type` picks its template; `default` covers the rest. `expanded: true` opens a branch.

## Events

`selectionChange` (two-way with `[(selection)]`), `nodeSelect`, `nodeUnselect`, `nodeExpand`, `nodeCollapse`.

## Accessibility

The chart is a layout of tables, not a tree widget: screen readers read the nodes in order, without levels. Where the hierarchy itself matters to the reader, give the same data as a nested list or a `baps-tree-table` too.
