# Listbox

The BAPS Design System **Listbox** (`baps-listbox`) is a standalone Angular wrapper around PrimeNG's `p-listbox` component. It provides single or multiple selection of values from a list of options. It is customized for both the **MyBKY** (pill radius, soft blue selections) and **Sampark** (flat corners, maroon branding, selected left accent bar indicator) styles.

Rows are rendered by [`baps-menu-item`](?path=/docs/components-molecules-menu-item--docs); the field variants of the same control are documented on [Input](?path=/docs/components-form-controls--docs).

## Usage

```html
<baps-listbox
  [options]="centers"
  optionLabel="name"
  optionValue="id"
  [(ngModel)]="selectedCenter"
/>
```

## When Not to Use

| Need | Use | Not this |
| --- | --- | --- |
| One value from a short list, inline in a form | `baps-select` | A listbox, which always occupies its full height |
| Several values from a long list | `baps-multiselect` | A listbox with `multiple` and no filter |
| Picking a person from the directory | `baps-users-dropdown` | A listbox of names — it has no avatar/role row |
| A hierarchy of options | `baps-treeselect` | A flat listbox with indented labels |

## Accessibility

- The panel is a `listbox` and each row an `option`; selection state is announced through `aria-selected`, which `baps-menu-item` sets.
- Give the control a programmatic label — `ariaLabel`, or a visible `<label>` associated with it. A panel with no accessible name is announced as "list box" and nothing else.
- Arrow keys move through options, `Space` / `Enter` selects, and `Home` / `End` jump to the ends. Filtering keeps focus in the filter field; arrow keys move into the filtered list.
- The selected left accent bar in the Sampark skin is decorative — selection is never communicated by that bar alone.
