# ColorPicker

`baps-color-picker` picks a colour from a saturation square and a hue strip. It wraps PrimeNG's `p-colorpicker` ([primeng.dev/colorpicker](https://primeng.dev/colorpicker)), which PrimeNG v21 lists as InputColor. The swatch is a 32px square with the field radius of the brand (MyBKY pill, Sampark 4px); the picker itself is PrimeNG's dark panel in both brands.

## Usage

```html
<label for="colour">Colour</label>
<baps-color-picker inputId="colour" formControlName="colour" />
```

## Events

`changed`, `shown`, `hidden`. The form gets the value itself.

## Accessibility

Name the swatch with a `<label for>` and `inputId`; without one PrimeNG reads it as "Select a color". On the swatch, Space opens the picker and Escape or Tab closes it, but choosing the colour itself needs a pointer: give keyboard users a text field for the hex value next to it where they must be able to set a colour.
