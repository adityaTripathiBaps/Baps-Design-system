# AutoComplete

`baps-autocomplete` is a text field that suggests matches as the user types. It wraps PrimeNG's `p-autocomplete` ([primeng.dev/autocomplete](https://primeng.dev/autocomplete)) and is skinned for both **MyBKY** and **Sampark** by the shared select styles, so the field and its panel match `baps-select`.

The app does the filtering: listen to `(completeMethod)`, read `$event.query`, and set `[suggestions]`. That keeps a server search, a local filter and a debounced API call the same shape. `delay` (300 ms) and `minQueryLength` control when the query fires.

For several values shown as chips, use [Chips input](?path=/docs/components-chips-input--docs): PrimeNG 21 deprecates AutoComplete's own `multiple`.

## Usage

```html
<baps-autocomplete
  ariaLabel="City"
  optionLabel="name"
  [suggestions]="cities"
  (completeMethod)="cities = search($event.query)"
  formControlName="city"
/>
```

## Events

`completeMethod` (the query), `selected`, `unselected`, `dropdownClick`, `cleared`, `shown`, `hidden`, `lazyLoad`, `keyUp`. The form gets the value itself; `cleared` reports `null`.

## Accessibility

Give the field a name: a `<label for>` with `inputId`, or `ariaLabel`. PrimeNG supplies the combobox role, `aria-expanded`, the listbox and the screen-reader messages (`searchMessage`, `emptySelectionMessage`, `selectionMessage`). Name the dropdown button with `dropdownAriaLabel`.
