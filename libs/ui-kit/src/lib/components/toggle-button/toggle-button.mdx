# ToggleButton

`baps-toggle-button` is a button that stays pressed: on or off, with a label and icon for each state. It wraps PrimeNG's `p-togglebutton` ([primeng.dev/togglebutton](https://primeng.dev/togglebutton)) as a boolean form control. It has the kit button's size in each brand (MyBKY 36px pill, Sampark 32px with a 4px radius; small and large follow the button too). Pressed, it fills grey: MyBKY from the theme, Sampark `#e1e0e0` (hover `#f3f2f2`, the secondary button's hover).

For a setting that applies at once, prefer `baps-toggle-switch`. For one choice out of several, use `baps-segmented`.

## Usage

```html
<baps-toggle-button onLabel="On" offLabel="Off" formControlName="notify" />
```

## Events

`changed` (`{ originalEvent, checked }`). The form gets the value itself; a toggle marks it touched.

## Accessibility

PrimeNG renders a button with `aria-pressed`. When the label changes with the state, keep it meaningful in both (not just "Yes" / "No"), or set `ariaLabel` to the setting's name.
