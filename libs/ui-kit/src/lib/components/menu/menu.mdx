# Menu

A navigation and action menu displaying a hierarchical list of items. `baps-menu` wraps PrimeNG's `p-menu`.

The menu can be used inline or as a popup overlay anchored to a trigger button. Submenus, icons, disabled items, and brand theming are supported.

## Accessibility

- Uses semantic `<ul role="menu">` and `<li role="none">` / `<a role="menuitem">` attributes.
- Popup menus close reliably when pressing <kbd>Esc</kbd> or clicking outside the panel.
- Disabled items receive `aria-disabled="true"` and are excluded from keyboard tab sequences.
