# Fieldset

Fieldset groups related content in a bordered box with a legend on the border, and can fold it away. `baps-fieldset` wraps PrimeNG's `p-fieldset` ([primeng.dev/fieldset](https://primeng.dev/fieldset)). Border, text and legend hover take the brand colours (MyBKY `#e4ecf1` / `#181b1d`, Sampark `#e1e0e0` / `#151414`).

For a titled block with actions in the header, `baps-card` or the accordion fit better; Fieldset suits a group of fields in a form.

## Usage

```html
<baps-fieldset legend="Family" [toggleable]="true" [(collapsed)]="folded">
  …
</baps-fieldset>
```

## Events

`collapsedChange` (two-way with `[(collapsed)]`), `beforeToggle`, `afterToggle`.

## Accessibility

PrimeNG renders a real `fieldset` and `legend`; a toggleable legend is a button with `aria-expanded` and `aria-controls`.
