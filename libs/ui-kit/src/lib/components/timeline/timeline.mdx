# Timeline

Timeline shows events in order along a line: a project's history, a family's visits. Use PrimeNG's `p-timeline` ([primeng.dev/timeline](https://primeng.dev/timeline)) with the `bapsTimeline` directive. Markers take the brand primary (MyBKY `#5f78b8`, Sampark `#c96868`) and the line the brand border (`#e4ecf1` / `#e1e0e0`).

## Usage

```html
<p-timeline bapsTimeline [value]="events">
  <ng-template #opposite let-e>{{ e.date }}</ng-template>
  <ng-template #content let-e>{{ e.status }}</ng-template>
</p-timeline>
```

## Accessibility

The timeline is a list of events with no roles of its own. Put the date in the content or the opposite text, not only in the marker, and keep the events in time order in `value`, which is also the reading order.
