# Timeline

Timeline shows events in order along a line: a project's history, a family's visits. `baps-timeline` wraps PrimeNG's `p-timeline` ([primeng.dev/timeline](https://primeng.dev/timeline)). Markers take the brand primary (MyBKY `#5f78b8`, Sampark `#c96868`) and the line the brand border (`#e4ecf1` / `#e1e0e0`).

## Usage

```html
<baps-timeline [value]="events">
  <ng-template pTemplate="opposite" let-e>{{ e.date }}</ng-template>
  <ng-template pTemplate="content" let-e>{{ e.status }}</ng-template>
</baps-timeline>
```

## Accessibility

The timeline is a list of events with no roles of its own. Put the date in the content or the opposite text, not only in the marker, and keep the events in time order in `value`, which is also the reading order.
