# Input Number

A numeric form control with min/max clamping, locale grouping, decimal precision, and keyboard-accessible spinner buttons. `baps-input-number` wraps PrimeNG's `p-inputnumber` and implements `ControlValueAccessor`.

Spinner buttons are enabled by default because every measured Sampark use has them. Set `[showButtons]="false"` only when the surrounding form does not use the spinner shape.

## Forms

The wrapper is a full `ControlValueAccessor`, including touched and disabled state, so both forms APIs work.

```html
<baps-input-number formControlName="attendance" [min]="0" [max]="100000" />
```

## Events

Angular follows the kit's existing value-event convention with `(valueChange)`. React keeps its platform convention with `onInput`. Both receive the normalized input event, including its numeric `value`.

## Accessibility

- Put the control inside a visible `<label>`, or associate a visible label with the nested input through your form-field pattern.
- The input exposes native spinbutton semantics and supports <kbd>Arrow Up</kbd> / <kbd>Arrow Down</kbd>.
- The increment and decrement actions use the kit's 12px plus/minus icons inside native buttons. Their `aria-label` values provide the accessible names, and both buttons remain keyboard reachable.
- Disabled state is native on the field and both buttons; no class-only disabling is used.
