# ConfirmDialog

A modal confirmation prompt driven imperatively by a service. `baps-confirm-dialog` wraps `baps-dialog` to deliver consistent modal styling, backdrop masking, focus trapping, and brand theming.

In Angular, add `<baps-confirm-dialog />` once in the application layout and trigger confirmations using `BapsConfirmationService.confirm()`. In React, wrap with `<BapsConfirmProvider>` and call `useConfirm()`.

## Accessibility

- Traps keyboard focus within the dialog while active.
- Restores focus to the trigger element when dismissed or accepted.
- <kbd>Esc</kbd> key dismisses the confirmation by default.
- Header and body elements are connected via `aria-labelledby` or `aria-label`.
