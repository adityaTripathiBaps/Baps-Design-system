# Dialog

A modal window for a decision or a short form. `baps-dialog` wraps PrimeNG’s `p-dialog` and projects its own header, body and footer.

## Usage

```html
<baps-dialog [(visible)]="open" header="Delete project" width="28rem" brand="sampark">
  <p>This cannot be undone.</p>
  <div dialog-footer>
    <baps-button label="Cancel" severity="secondary" [outlined]="true" (click)="open = false" />
    <baps-button label="Delete" severity="danger" (click)="remove()" />
  </div>
</baps-dialog>
```

### Draggable

`[draggable]="true"` moves the panel by its header (the header shows a move cursor) and `keepInViewport` keeps it on screen. Off by default: a blocking decision should not move under the cursor. Use it for non-blocking panels.

<Canvas of={DialogStories.Draggable} />

### Maximizable and responsive

`[maximizable]="true"` adds a maximize button; `breakpoints` sets the width per max-width breakpoint, e.g. `{ '1199px': '75vw', '575px': '90vw' }`.

<Canvas of={DialogStories.MaximizableResponsive} />

### Position

`position` docks the panel to an edge or corner: left, right, top, bottom, topleft, topright, bottomleft, bottomright (default center).

<Canvas of={DialogStories.Position} />

### Without modal

`[modal]="false"` leaves the page usable; pair it with `[blockScroll]="false"`.

<Canvas of={DialogStories.WithoutModal} />

### Headless and full screen

`[showHeader]="false"` drops the title bar when the body has its own heading (give it `ariaLabel`); a full-screen panel is a 100vw width with a 100vh style. `maskStyleClass` and `contentStyleClass` add classes to the mask and the content.

## When Not to Use

| Need | Use | Not this |
| --- | --- | --- |
| A message that needs no decision | `baps-alert`, or a toast | A dialog the user must dismiss |
| A long form or a filter panel | `baps-drawer` | A dialog tall enough to scroll |
| A confirmation on a row action | `baps-dialog` with `role="alertdialog"` | A native `confirm()` |

## Accessibility

### Screen Reader

- `role` defaults to `dialog`; pass `role="alertdialog"` for a destructive confirmation so it is announced more urgently.
- `header` becomes the accessible name. A dialog with no header needs an `ariaLabel`.
- Focus returns to the element that opened it on close.

### Keyboard Support

| Key | Function |
| --- | --- |
| <kbd>Tab</kbd> | Cycles focus inside the dialog — focus is trapped while it is open. |
| <kbd>Esc</kbd> | Closes it, unless `closeOnEscape` is off. |
