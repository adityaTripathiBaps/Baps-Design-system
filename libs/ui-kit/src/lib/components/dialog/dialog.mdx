# Dialog

A modal window for a decision or a short form. `baps-dialog` wraps PrimeNG’s `p-dialog` and projects its own header, body and footer.

## Usage

```html
<baps-dialog [(visible)]="open" header="Delete project" width="28rem" brand="sampark">
  <p>This cannot be undone.</p>
  <div dialog-footer>
    <baps-button label="Cancel" severity="secondary" [outlined]="true" (click)="open = false" />
    <baps-button label="Delete" severity="danger" (click)="remove()" />
  </div>
</baps-dialog>
```

## When Not to Use

| Need | Use | Not this |
| --- | --- | --- |
| A message that needs no decision | `baps-alert`, or a toast | A dialog the user must dismiss |
| A long form or a filter panel | `baps-drawer` | A dialog tall enough to scroll |
| A confirmation on a row action | `baps-dialog` with `role="alertdialog"` | A native `confirm()` |

## Accessibility

### Screen Reader

- `role` defaults to `dialog`; pass `role="alertdialog"` for a destructive confirmation so it is announced more urgently.
- `header` becomes the accessible name. A dialog with no header needs an `ariaLabel`.
- Focus returns to the element that opened it on close.

### Keyboard Support

| Key | Function |
| --- | --- |
| <kbd>Tab</kbd> | Cycles focus inside the dialog — focus is trapped while it is open. |
| <kbd>Esc</kbd> | Closes it, unless `closeOnEscape` is off. |
