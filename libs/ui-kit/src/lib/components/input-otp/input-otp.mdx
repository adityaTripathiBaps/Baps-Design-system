# Input OTP

A one-time-code field with one box per digit. `baps-input-otp` wraps PrimeNG's `p-inputotp`.

- Each box is a `pInputText`, so border, hover, focus ring, error and disabled come from the brand input skin, the same as a text field.
- Figma ships 4 and 6 digits. Six digits are split 3-3 with a "-", as in Figma. Set `separator` to override that.
- Typing moves to the next box, Backspace on an empty box moves back, and pasting a whole code fills every box.
- The first box gets `autocomplete="one-time-code"`, so phones offer the code from the SMS.

Label and hint are not part of the component. Compose them around it like any other field.

```html
<label for="otp">Verification code</label>
<baps-input-otp inputId="otp" [(ngModel)]="code" [length]="6" />
```
