# InputMask

`baps-input-mask` takes input in a fixed format: a phone number, a date, a serial number. It wraps PrimeNG's `p-inputmask` ([primeng.dev/inputmask](https://primeng.dev/inputmask)). The inner field is a `pInputText`, so it is the kit input in both brands (MyBKY 36px pill, Sampark 32px with a 4px radius), sizes included.

## Usage

```html
<label for="ssn">SSN</label>
<baps-input-mask inputId="ssn" mask="999-99-9999" formControlName="ssn" />
```

In `mask`, `9` is a digit, `a` a letter (`characterPattern` changes which), `*` either; anything else is typed for the user. `unmask` sends only what the user typed, without the literals. An incomplete value is cleared on blur unless `autoClear` is false.

## Events

`completed`, `focused`, `blurred`, `inputChange`, `keydown`, `cleared`. The form gets the value itself.

## Accessibility

Name the field with a `<label for>` and `inputId`, or `ariaLabel`. Show the expected format in the label or the placeholder: the slots alone do not say what goes in them.
