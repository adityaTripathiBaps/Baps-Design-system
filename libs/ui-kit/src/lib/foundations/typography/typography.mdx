# Typography

The type scale, weights and tracking both brands are set in.

<ResourceTabs sections={['Usage', 'Examples', 'Accessibility']} />

Source: Figma [node 13193:58310](https://www.figma.com/design/xc0L2xnREMgjyb5XcKyLIz/%F0%9F%9F%A2-Sampark-Portal?node-id=13193-58310) — the "Typography" sheet. Everything on it is **Inter**, at **130% leading**, with **0 tracking** except the Caps styles at 5%.

## Usage

Sizes, weights and tracking all come from tokens; nothing here should be a literal in a component.

```scss
font-family: var(--font-family-mybky);
font-size: var(--font-size-sm);          /* 14px — body text for both brands */
font-weight: var(--font-weight-medium);  /* 500 */
line-height: var(--font-line-height-snug); /* 1.3 — the sheet's 130% */

/* Uppercase labels are the one place tracking is not zero */
text-transform: uppercase;
letter-spacing: var(--font-letter-spacing-caps); /* 0.05em */
```

## Reconciliation with the Figma sheet

The sheet runs `10 / 12 / 14 / 16 / 18 / 20 / 24 / 30 / 36 / 40`. Three of those steps were missing and have been added: `2xs` (10px), `4xl` (36px) and `5xl` (40px). The `letterSpacing` tier is also new — there was no tracking token at all, so the Caps styles had nothing to reference.

Two differences remain, deliberately:

| | Figma sheet | Repo | Why it stands |
| --- | --- | --- | --- |
| Step above 24px | 30px | `3xl` = 28px | `3xl` is commented *"mybky h1 only"*. The sheet is the Sampark file, so moving it would change MyBKY's h1 to satisfy a Sampark spec. |
| Heading leading | 130% everywhere | Showcase renders headings at `1.2` | The showcase below hard-codes its own line-heights. `--font-line-height-snug` is already 1.3 and is what components consume. |

The scale also carries `lineHeight.tight`, `normal` and `relaxed`, which the sheet does not define — they exist for prose and dense table rows.

## Font Stack & Loading

1. **Inter Variable** — the primary UI font.
   - Registered locally via `@font-face` pointing at a bundled variable TTF (`Inter-VariableFont_opsz,wght.ttf`) in `libs/ui-kit/src/lib/styles/layout/fonts/`.
   - One file covers weights `100`–`900` plus the optical size (`opsz`) axis.
   - Stack: `'Inter Variable', 'Inter', sans-serif`.
   - `font-display: swap`, so there is no flash of invisible text.
2. **Roboto** — fallback, and the base PrimeNG's Material preset expects (weights `400`/`500`/`700`). Loaded through `@fontsource/roboto` in the Storybook preview config.

## Root Font Sizing (Rem Baseline)

Two root sizes, on purpose:

- **Figma baseline** — tokens and spacing are authored against `1rem = 16px` (`html { font-size: 16px }`).
- **PrimeNG scaling** — the app shell scales components down with `@layer app-styles { html { font-size: 14px } }` for the compact desktop density.

The 16px rule is unlayered, and unlayered CSS beats `@layer` regardless of order — which is why the baseline holds in Storybook while the app still gets its 14px.

## OpenType features

17 Inter features are enabled globally so rendering matches Figma:

```css
font-feature-settings:
  'case' on, 'cpsp' on, 'salt' on, 'ss01' on, 'ss03' on, 'ss04' on,
  'cv01' on, 'cv02' on, 'cv03' on, 'cv04' on, 'cv05' on, 'cv06' on,
  'cv07' on, 'cv08' on, 'cv09' on, 'cv10' on, 'cv11' on;
```

The ones that visibly matter:

- **`case`** — case-sensitive forms; shifts punctuation up to sit with all-caps text.
- **`cpsp`** — capital spacing; opens up runs of uppercase, which pairs with the Caps tracking above.
- **`cv05`** — puts a tail on lowercase `l` so it stops reading as `I` or `1`.
- **`ss01`/`ss03`** — single-storey alternates for `a` and `g`.

## Accessibility

- Body text is `sm` (14px) for both brands. Below `xs` (12px) is for dense metadata only — never for anything the user has to read carefully.
- Line height of 1.3 is tight for long prose; `relaxed` (1.6) exists for paragraphs, and the docs shell uses it.
- Never use weight alone to carry meaning. A bold row in a table is not accessible information; a label is.
- Uppercase reduces word-shape cues and is slower to read, so Caps styles are for short labels only, never sentences.
