## Statuses

| Status | Means | Example |
| --- | --- | --- |
| **Passed** | Nothing to do | Every var() resolves |
| **Warning** | Renders correctly today, drifts tomorrow | `border-radius: 4px` that happens to equal `--radius-sampark-default` |
| **Error** | Renders wrong, or not at all | A var() nothing defines; body text under 4.5:1 |
| **Deprecated** | Still works, scheduled for removal | A token whose source comment says so |

Warnings are the migration backlog, ranked by file. They are not fixed by editing component CSS to satisfy the count — the existing appearance is the baseline (non-negotiable #4), so each literal is swapped for the token that already renders the same value.

## Running it

```bash
node tools/audit-foundations.mjs           # rewrite audit.snapshot.json
node tools/audit-foundations.mjs --check   # exit 1 if any check is an Error
```

The snapshot is committed, so this page shows the state as of its date rather than scanning in the browser. Re-run it after a token or style change and commit the result with the change.
