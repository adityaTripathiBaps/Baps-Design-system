# Installation

Install matching tarballs for the kit and `@org/tokens`. The current route is
tarball delivery; a private registry is planned but is not configured.

For the complete procedures, read the
[consumer integration guide](https://github.com/adityaTripathiBaps/Baps-Design-system/blob/main/docs/CONSUMER-INTEGRATION-GUIDE.md)
and the
[versioning and upgrade policy](https://github.com/adityaTripathiBaps/Baps-Design-system/blob/main/docs/VERSIONING-AND-UPGRADE.md).

## Compatibility

| Package                   | Framework peers                                                 | Tokens              | Toolchain verified here        |
| ------------------------- | --------------------------------------------------------------- | ------------------- | ------------------------------ |
| `@org/ui-kit` 0.1.x       | Angular `^21.2.0`, PrimeNG `^21.1.3`, `@primeuix/themes ^2.0.3` | `@org/tokens 0.0.1` | TypeScript 6.0.3, Node 22.22.2 |
| `@org/ui-kit-react` 0.1.x | React / React DOM `^19.2.7`                                     | `@org/tokens 0.0.1` | TypeScript 6.0.3, Node 22.22.2 |

Current Angular and PrimeNG majors only are supported. Older consumers use the
upgrade-first path in the versioning guide. The Next.js App Router client and
server shapes are type-checked, but this repository does not pin a Next.js
package version.

## Install and load CSS

Angular:

```ts
import '@org/tokens/css';
import '@org/ui-kit/styles';
import 'primeicons/primeicons.css';
```

React or Next.js:

```ts
import '@org/tokens/css';
import '@org/ui-kit-react/styles';
import 'primeicons/primeicons.css';
```

Load tokens first and application overrides last. Register Angular's `MyBky`
PrimeNG preset with `providePrimeNG`; put interactive React/Next components in
a client boundary.

The full style bundle includes Inter's `@font-face`. The application still
owns root typography:

```css
html {
  font-size: 16px;
  font-family: var(--font-family);
  font-feature-settings: var(--font-feature-settings);
}

button,
input,
textarea,
select {
  font-feature-settings: inherit;
}
```

Per-component CSS such as `@org/ui-kit/styles/button` includes no font face or
font-family variable; consumers choosing it supply and verify their own
typography.

## Brands and dark mode

MyBKY is the default. Use `.baps-ds-sampark` on a page scope or
`.baps-sampark` on one instance. Apply `.baps-dark` to both `<html>` and
`<body>` so root token references and inherited values resolve consistently.

## Verify

Build the real consumer in production mode, then check both brands in light
and dark, keyboard behavior, axe results, icons, typography and visual
baselines. A successful type-check alone is not compatibility proof.
